M-VAVE FM-1 自製韌體

  • CHAIN-1 — 安裝 · 試玩
    單音合成器，固定鏈 OSC → FILTER → EG → MOD → DELAY → REVERB，加琶音器
  • PRISM-1 — 安裝 · 試玩
    照 Vital 架構的 wavetable 合成器
  • TOYBOX-4 — 安裝 · 試玩
    OP-1 式的 4 軌口袋工作室

安裝要用 Chrome 或 Edge：電腦用 USB 線，或 Android 手機用 USB-C OTG 線連接 FM-1。iPhone 的瀏覽器沒有 Web MIDI，不能用。安裝有風險，請先準備好原廠韌體以便刷回。本專案與 M-VAVE 無關。
