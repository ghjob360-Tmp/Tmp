PRISM-1

PRISM-1 1.2

照 Vital 架構的 wavetable 合成器：8 voices、3 個 wavetable 振盪器加 sampler、2 個濾波器、18 個調變源、32 槽調變矩陣、9 種效果。

給 M-VAVE FM-1 的自製韌體，原始碼：<https://github.com/ghjob360-Tmp/Tmp/tree/claude/mwave-fm1-custom-firmware-01qpvb/prism1>

  • 安裝到 FM-1：用 Chrome 或 Edge（電腦，或 Android 手機用 USB-C OTG 線連接 FM-1）
  • 在瀏覽器裡試玩
  • 下載韌體包

安裝有風險，請自行負責；先準備好原廠韌體（M-VAVE 的 FM-1.fwsc）以便刷回。本專案與 M-VAVE 無關。

A custom firmware for the M-VAVE FM-1. Install (Chrome or Edge, on a computer or an Android phone over USB-C), try it in the browser, or download the package. Not affiliated with M-VAVE; install at your own risk.
